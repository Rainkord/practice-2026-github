Что изучим?

Пять классических шифров от простого к сложному — с историей, объяснением и заданиями

ШИФР 01

Код Морзе

Каждая буква — уникальная комбинация точек и тире. Первая международная система передачи закодированных сообщений, изобретена Сэмюэлом Морзе в 1838 году.

· — · —
ШИФР 02

Атбаш

Древнейший шифр подстановки: алфавит записывается в обратном порядке. Использовался для шифрования религиозных текстов начиная с 600 года до н.э.

A ↔ Z
ШИФР 03

Шифр Цезаря

Сдвиг каждой буквы на фиксированное число позиций. Юлий Цезарь использовал сдвиг 3 для переписки с полководцами около 50 года до н.э.

+3 позиции
ШИФР 04

Шифр Виженера

Полиалфавитный шифр с ключевым словом — как несколько шифров Цезаря одновременно. Считался невзламываемым почти 300 лет.

KEY → сдвиги
ШИФР 05

Шифр Вернама

Единственный в мире абсолютно стойкий шифр при правильном использовании. На его принципе работала «красная линия» Москва–Вашингтон.

О проекте

Образовательный сайт по классической криптографии с интерактивным маскотом-лисёнком

🎯 Цель проекта

  • Создать доступный образовательный ресурс по основам криптографии
  • Познакомить пользователей с пятью классическими шифрами
  • Обеспечить интерактивное обучение через практические задания
  • Сделать изучение шифров увлекательным с помощью маскота-лисёнка

📋 Задачи

  • Разработать контент по каждому из 5 шифров с историческими справками
  • Создать систему заданий: дешифрование, шифрование, поиск ключа
  • Реализовать маскота с тремя эмоциями и всплывающими подсказками
  • Организовать прогрессивную структуру: пролог → задания → финал

💡 Актуальность

В эпоху цифровых технологий понимание основ криптографии становится всё более важным. Современная интернет-безопасность, мессенджеры, банковские системы — всё построено на принципах классических шифров.

Большинство обучающих материалов по криптографии либо слишком сложны, либо слишком скучны. Наш проект заполняет этот пробел: интерактивный маскот делает обучение увлекательным для широкой аудитории.

🦊 Про маскота

Лисёнок — ваш проводник по миру шифров. Три состояния: обычное (навигация и приветствие), объясняющее (рассказывает про шифр) и умное (делится историческими фактами). Нажмите на иконку в правом углу!

Структура обучения

Каждый шифр изучается по единому принципу: пролог → задания → итог

ШАГ 01

Пролог

Маскот рассказывает историю шифра на затемнённом фоне. Историческая справка курсивом. Затем фон светлеет и появляется подробное объяснение принципа работы.

ШАГ 02

Три задания

Дешифрование, шифрование, поиск ключа. Маскот объясняет каждое задание. В нижнем углу — кнопка для повторного объяснения если забыл.

ШАГ 03

Финал

После всех пяти шифров маскот благодарит за прохождение и выводит итоговую сводку изученных методов шифрования.

Журнал проекта

Записи о прогрессе, заметки и новости разработки

2026-05-04 Старт

Начало работы над проектом

Сформулирована идея проекта — образовательный сайт по криптографии с интерактивным маскотом. Определён список из 5 шифров: Морзе, Атбаш, Цезарь, Виженер, Вернам. Нарисован маскот-лисёнок с тремя эмоциями, согласован общий стиль. Создан репозиторий на GitHub, настроена структура папок docs/, site/, reports/.

2026-05-12 Контент

Подготовка контент-плана и заданий

Написан детальный контент-план для каждого шифра: исторические справки, объяснения принципа работы, тексты маскота для пролога и каждого задания. Для каждого шифра подготовлено по три задания (дешифрование, шифрование, поиск ключа). Все ответы проверены. Определена навигационная структура: главный экран → меню шифров → пролог → задания → финал.

2026-05-20 Разработка

Создание веб-сайта и интеграция маскота

Реализован сайт на чистом HTML/CSS/JS без внешних зависимостей. Цветовая схема подобрана под маскота — тёплые оранжево-янтарные тона на тёмном фоне. Маскот интегрирован с тремя состояниями (normal, explain, smart), переключающимися при смене страницы. Реализованы все пять обязательных разделов по заданию. Файлы запушены в репозиторий на GitHub.
