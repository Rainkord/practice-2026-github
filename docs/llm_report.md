## 2. Приобретённые знания

Курс охватывает ключевые аспекты экосистемы машинного обучения и методы обработки текстовых данных — навыки, напрямую применимые в задачах анализа угроз и автоматизации ИБ-процессов.

### 2.1 Архитектура Transformer

Освоен механизм self-attention, а также три основных семейства моделей:

- **Encoder-only (BERT и аналоги)** — классификация инцидентов, NER, выявление паттернов атак
- **Decoder-only (GPT и аналоги)** — генерация текста, автодополнение кода, создание AI-ассистентов
- **Encoder-Decoder (T5, BART)** — машинный перевод, реферирование, seq2seq-преобразования

### 2.2 Стек библиотек Hugging Face

- **`transformers`** — токенизация (BPE, WordPiece), управление `attention_mask`, параметры `truncation`/`padding`, сборка инференс-пайплайнов через `pipeline()`
- **`datasets`** — загрузка, фильтрация и парсинг логов, разметка больших корпусов с оптимизацией памяти
- **`evaluate`** — расчёт метрик Accuracy, F1-score, Precision, Recall для оценки качества классификаторов

### 2.3 Fine-Tuning

Изучен процесс дообучения моделей на специализированных датасетах через `Trainer` и `TrainingArguments`. Это позволяет адаптировать LLM под ИТ/ИБ-лексику: распознавание CVE-идентификаторов, классификацию отчётов об инцидентах, анализ логов.

## 3. Применение LLM в ходе практики

В процессе разработки сайта языковая модель использовалась как AI Pair Programmer — помощник, берущий на себя рутинные задачи: генерацию HTML/CSS, написание контента и отладку вёрстки.

### 3.1 Генерация HTML-структур

Написание идентичной шапки для пяти страниц вручную — монотонная задача. LLM взяла её на себя.

> **Задача:** сформировать блок `<header>` с логотипом, названием вуза и навигацией, где активный пункт получает класс `active`.
>
> **Результат:** модель сгенерировала семантически корректный `<header class="site-header">`, который затем тиражировался по страницам с переносом класса `.active`.

### 3.2 CSS-сетки: Grid и Flexbox

Страница `members.html` требовала карточного отображения четырёх ИТ-отделов с адаптивностью под мобильные устройства.

> **Задача:** двухколоночная сетка, которая при ширине экрана менее 650 px перестраивается в одну колонку.
>
> **Результат:** LLM сгенерировала следующий CSS, встроенный в `<style>` страницы:

```css
.teams {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1.5rem;
    margin-top: 1.5rem;
}

@media (max-width: 650px) {
    .teams { grid-template-columns: 1fr; }
}
```

Адаптивный интерфейс был получен без ручной отладки медиазапросов.

### 3.3 Текстовый контент с ИБ-спецификой

Разделы «Актуальность» и «Проблематика» (`about.html`, `index.html`) требовали академически выверенного текста об образовательном киберполигоне.

> **Задача:** тезисы о высокой стоимости коммерческих платформ и кадровом дефиците в сфере ИБ.
>
> **Результат:** модель сформировала структурированный контент, опирающийся на реальные проблемы ИБ-образования. Текст без правок лёг в блоки `<section class="info-text fullwidth">` и `<div class="feature-card">`, что сэкономило время на копирайтинге.

## 4. Вывод

Курс Hugging Face NLP Course дал системное понимание принципов работы LLM и практические инструменты для их применения в прикладных задачах.

Разработка сайта по обучению криптографии подтвердила эффективность подхода AI-Assisted Development: использование языковых моделей для генерации HTML, написания адаптивных CSS-сеток и подготовки контента кратно ускорило разработку фронтенда и позволило сосредоточиться на проектировании архитектуры платформы.
