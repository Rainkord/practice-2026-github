# Описание проекта: «Дешифратор для студентов и школьников»

## Цель проекта

Доработать рабочее веб-приложение с реализацией 5+ алгоритмов шифрования, обеспечив удобный и доступный инструмент для знакомства с криптографией для школьников и студентов младших курсов.

## Задачи проекта

- Провести анализ существующих образовательных платформ и приложений по криптографии (CryptoHack, CrypTool 2, ChameleonLab и др.).
- Реализовать не менее 5 классических алгоритмов шифрования (подстановочные, перестановочные шифры и др.).
- Создать обучающий контент: теоретические справки и практические задания разного уровня сложности.
- Обеспечить удобство использования: по результатам юзабилити-тестирования не менее 90% участников должны выполнить базовую операцию шифрования без инструкции.
- Интегрировать элементы геймификации для повышения вовлечённости пользователей.
- Реализовать личный кабинет с авторизацией, профилем и историей шифрования.

## Актуальность

Современные школьники и студенты младших курсов зачастую воспринимают математику и алгоритмику как абстрактные дисциплины, оторванные от реальной жизни. Существующие образовательные ресурсы по криптографии либо слишком сложны и академичны, либо не дают глубокого понимания процессов шифрования.

Проект решает сразу несколько задач:
- **Наглядно демонстрирует** применение математических алгоритмов на практике.
- **Является профориентационным инструментом**, пробуждая интерес к таким востребованным профессиям, как криптограф, специалист по кибербезопасности, программист.
- **Развивает алгоритмическое мышление и логику** — ключевые компетенции XXI века.

## Проблематика

В ходе анкетирования 42 студентов технических специальностей было выявлено:
- **56%** не хватает визуализации алгоритмов.
- **51%** ощущают разрыв между теорией и практикой.
- **76%** положительно относятся к геймификации в обучении.

Анализ конкурентов показал, что на рынке отсутствует удобное веб-решение для начинающих: CryptoHack ориентирован на продвинутых пользователей, CrypTool 2 — десктопное приложение с перегруженным интерфейсом, ChameleonLab имеет хорошую визуализацию, но ограниченный набор алгоритмов.

## Новизна проекта

- Комплексный подход к юзабилити.
- Интеграция академических знаний в обучающий процесс.
- Геймификация: персонажи-помощники (маскоты), интеллектуальные подсказки, сценарии обучения.

## Этапы реализации

| Этап | Содержание |
|---|---|
| **Этап 1: Инфраструктура** | Настройка Docker, организация работы через GitHub |
| **Этап 2: Бэкенд** | Добавление 4+ новых шифров, написание юнит-тестов, серверная логика |
| **Этап 3: Интерфейс** | Личный кабинет, авторизация, адаптивная вёрстка |
| **Этап 4: Геймификация** | Разработка сценария обучения, отрисовка маскотов, подсказки |
