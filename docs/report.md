## 1. Выбор темы и исследование

### 1.1 Постановка задачи

Hyprland — современный тайловый Wayland-композитор, который набирает популярность среди Linux-пользователей. Весь менеджмент обоев в нём осуществляется через конфигурационные файлы двух утилит:

- **hyprpaper** — фоновый демон для статичных изображений, управляемый через `~/.config/hypr/hyprpaper.conf` и IPC-команды `hyprctl hyprpaper`
- **mpvpaper** — обёртка над mpv, позволяющая воспроизводить видеофайлы или GIF в качестве обоев

Типичный рабочий процесс: пользователь вручную редактирует текстовый конфиг, перезапускает демон, проверяет результат. При использовании нескольких мониторов это становится повторяющейся операцией, неудобной для ежедневного использования.

**Проблема:** отсутствие графического интерфейса для быстрой смены обоев на одном или нескольких мониторах сразу.

### 1.2 Анализ аналогов

| Утилита | Тип | Видео | Мультимонитор | GUI |
|---|---|---|---|---|
| hyprpaper (сам демон) | CLI/конфиг | ❌ | ✅ | ❌ |
| swww | CLI | ❌ | ✅ | ❌ |
| waypaper | GUI (Python/GTK) | ❌ | частично | ✅ |
| mpvpaper | CLI | ✅ | ✅ (ручной) | ❌ |
| **HyprWall** | **GUI (C++/Qt6)** | **✅** | **✅** | **✅** |

Основной конкурент — **waypaper** — не поддерживает видеообои и имеет ограниченную поддержку мультимонитора. HyprWall закрывает оба пробела.

### 1.3 Изученные технологии

- **Qt6 / C++** — GUI-фреймворк, сигналы и слоты, `QProcess`, `QListWidget` в режиме иконок, асинхронная загрузка превью через `QtConcurrent`
- **hyprpaper IPC** — протокол `hyprctl hyprpaper preload / wallpaper`
- **mpvpaper CLI** — параметры `--panscan`, `--keepaspect`, `--video-rotate`, `--volume`
- **CMake** — сборка Qt6-проекта (`find_package(Qt6 COMPONENTS Widgets Concurrent)`)
- **systemd user-сервисы** — автозапуск через `~/.config/systemd/user/hyprwall.service`
- **PKGBUILD** — упаковка для AUR

## 2. Реализация прототипа (MVP)

### 2.1 Архитектура приложения

```
┌─────────────────────────────────────────┐
│              main.cpp                   │  Точка входа, QApplication
└───────────────┬─────────────────────────┘
                │
┌───────────────▼─────────────────────────┐
│            MainWindow                   │  Главное окно (логика UI)
│  ┌──────────────┐  ┌──────────────────┐ │
│  │  MonitorBar  │  │  GalleryPanel    │ │
│  └──────────────┘  └──────────────────┘ │
└───┬───────────────────────┬─────────────┘
    │                       │
┌───▼────────────┐  ┌───────▼──────────────┐
│ ConfigManager  │  │  WallpaperApplier    │
│ (JSON-хранилище│  │  (IPC + QProcess)    │
│  настроек)     │  └──────────────────────┘
└────────────────┘
        │
┌───────▼─────────────┐
│  MonitorDetector    │  hyprctl monitors -j
└─────────────────────┘
```

**Модули:**

- `main.cpp` — инициализация `QApplication`, тёмная тема, запуск `MainWindow`
- `MainWindow` — логика UI, состояние (`m_pending`), слайдшоу-таймеры (`m_ssState`), кэш превью (`m_thumbCache`)
- `MonitorDetector` — получает список мониторов через `hyprctl monitors -j`, парсит JSON
- `ConfigManager` — синглтон, хранит конфигурации в `~/.config/HyprWall/config.json`
- `WallpaperApplier` — применяет обои: IPC для изображений, mpvpaper для видео
- `Types.h` — структуры `MonitorInfo`, `WallpaperConfig`, `GalleryItem`; перечисления `FillMode`, `WallpaperRotation`
- `Strings.h` — строки интерфейса на RU/EN

### 2.2 Ключевые технические решения

#### Двойной механизм применения обоев

```cpp
bool WallpaperApplier::apply(const WallpaperConfig &cfg) {
    if (isVideoFile(cfg.filePath)) {
        // Видео: запуск mpvpaper
        stopVideo(cfg.monitorName);
        QString opts = mpvOptions(...);
        return QProcess::startDetached("mpvpaper",
            {"-o", opts, cfg.monitorName, cfg.filePath});
    }
    // Изображение: сначала IPC (без перезапуска демона)
    if (hyprpaperRunning()) {
        if (applyImageIpc(cfg)) return true;
    }
    // Фолбэк: перезапись conf + pkill + restart
    writeHyprpaperConf(...);
    QProcess::execute("pkill", {"-x", "hyprpaper"});
    return QProcess::startDetached("hyprpaper", {});
}
```

IPC-метод применяет обои без перезапуска демона — это устраняет «моргание» экрана.

#### Определение мониторов

```cpp
QList<MonitorInfo> MonitorDetector::detect() {
    QProcess p;
    p.start("hyprctl", {"monitors", "-j"});
    p.waitForFinished(3000);
    QJsonArray arr = QJsonDocument::fromJson(
        p.readAllStandardOutput()).array();
    // Парсинг: name, description, x, y, width, height, scale
}
```

#### Асинхронный кэш превью

Превью загружаются в фоновых потоках через `QtConcurrent::run`. Механизм «поколений» (`m_thumbGeneration`) предотвращает применение устаревших результатов при быстрой смене галереи.

#### Слайдшоу

Каждый монитор имеет независимый `QTimer` в `m_ssState`. При срабатывании вызывается `WallpaperApplier::applySlideshowTick`, который случайно выбирает файл из галереи с учётом режима фильтрации (только фото / только видео / оба).

### 2.3 Пользовательский интерфейс

Главное окно — три зоны:

1. **MonitorBar** (верх) — плашки мониторов; клик выбирает монитор для настройки
2. **Панель настроек** (лево) — fill-mode, поворот, аудио/громкость, слайдшоу, автозапуск, язык, bind-hint
3. **Галерея** (право) — `QListWidget` в `IconMode` с превью 200×150, добавление/удаление, клик применяет обои

Окно без системных декораций: drag реализован через `mouseMoveEvent`, фон — через `paintEvent`.

### 2.4 Инструкция по сборке

```bash
# Зависимости (Arch Linux)
sudo pacman -S qt6-base cmake gcc hyprpaper mpvpaper

# Сборка
git clone https://github.com/Rainkord/HyprWall.git

cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)

# Запуск
./build/hyprwall

# Установка через AUR
yay -S hyprwall
```

## 3. Раздел «Модификация» — функции сверх базовой реализации

Базовая реализация: выбор изображения → применение на один монитор.

### 3.1 Поддержка видеообоев (mpvpaper)
Автоматическое определение типа файла по расширению. Для видео отображаются дополнительные элементы управления (аудио, громкость). При смене видео на изображение mpvpaper корректно завершается.

### 3.2 Независимое слайдшоу для каждого монитора
Каждый монитор имеет собственный таймер с настраиваемым интервалом (1 мин / 5 мин / 15 мин / 30 мин / 1 ч / 2 ч) и режимом медиа (фото / видео / всё). Слайдшоу нескольких мониторов работают параллельно.

### 3.3 Apply All
«Применить ко всем мониторам» — `WallpaperApplier::applyAll` оптимизирует запуск: hyprpaper стартует один раз для всех изображений, mpvpaper — отдельно для каждого монитора с видео.

### 3.4 Поворот изображения
Поворот на 90°/180°/270° через `QImage::transformed`, результат сохраняется в `~/.cache/HyprWall` без изменения оригинала.

### 3.5 Автозапуск через systemd
Переключатель вызывает `systemctl --user enable/disable hyprwall`. Файл юнита поставляется с пакетом.

### 3.6 Двуязычный интерфейс (RU/EN)
Вся строковая база в `Strings.h`. Переключение языка — мгновенно через `retranslateUi()` без перезапуска.

### 3.7 Асинхронный кэш превью
Загрузка превью в `QtConcurrent::run` — UI не зависает при добавлении большого количества файлов.

### 3.8 Упаковка в AUR (PKGBUILD)
Готовый `PKGBUILD` для Arch User Repository — установка одной командой `yay -S hyprwall`.
