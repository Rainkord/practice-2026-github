# Отчёты в бинарных форматах

В этой папке хранятся файлы итогового отчёта по проектной (учебной) практике.

## Файлы

| Файл | Описание |
|---|---|
| [practice_report_template.docx](practice_report_template.docx) | Шаблон отчёта, предоставленный кафедрой |
| [practice_report_content.md](practice_report_content.md) | Готовый текст отчёта для вставки в шаблон (plain text, без MD-разметки) |
| practice_report.docx | Заполненный отчёт в формате DOCX (после заполнения шаблона) |
| practice_report.pdf | Заполненный отчёт в формате PDF (после заполнения шаблона) |

## Краткое содержание отчёта

Отчёт охватывает все этапы учебной практики:

**Обязательная часть:**
- Настройка Git и репозитория (22 апреля 2026)
- Markdown-документация проекта (4 мая 2026)
- Создание веб-сайта «Дешифратор для студентов и школьников» (20 мая 2026)
- Прохождение курса Hugging Face NLP Course
- Посещение экскурсии в Яндекс (17 апреля 2026)

**Вариативная часть (вариант 2.2 — реализация технологии с нуля):**
- HyprWall — GUI-утилита для управления обоями (изображения + видео) в Hyprland
- Репозиторий: https://github.com/Rainkord/HyprWall
- Стек: C++, Qt6, CMake, hyprpaper IPC, mpvpaper
- Дополнительные функции: слайдшоу, Apply All, поворот, автозапуск systemd, RU/EN, AUR-пакет
