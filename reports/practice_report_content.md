ВВЕДЕНИЕ

В рамках проектной (учебной) практики были изучены современные инструменты разработки программных проектов, системы контроля версий, технологии веб-разработки и возможности применения больших языковых моделей (LLM) в процессе создания программных продуктов.

Основной задачей практики являлось получение практических навыков работы с современными ИТ-инструментами, освоение работы с Git и Markdown, создание собственного статического веб-сайта, а также реализация самостоятельного программного проекта в рамках вариативной части задания.

В ходе практики были изучены основы работы с системой контроля версий Git, язык разметки Markdown, технологии HTML, CSS и JavaScript, а также возможности использования искусственного интеллекта и больших языковых моделей для автоматизации разработки интерфейсов и генерации контента.

Дополнительно в рамках практики был пройден курс Hugging Face NLP Course, посвящённый современным технологиям обработки естественного языка и архитектурам Transformer, а также посещена экскурсия в офис компании Яндекс, в ходе которой были изучены особенности организации процессов разработки в крупных ИТ-компаниях.

В качестве вариативной части задания был выбран вариант 2.2 — практическая реализация технологии с нуля. Результатом стала GUI-утилита HyprWall для управления обоями рабочего стола в оконном менеджере Hyprland под Linux.


1. Общая информация о проекте

Название проекта

HyprWall — графическая утилита для управления обоями в Hyprland.

Цели и задачи проекта

Целью проекта HyprWall является создание удобного графического приложения, которое позволяет пользователям Hyprland настраивать обои рабочего стола без необходимости вручную редактировать конфигурационные файлы.

В Hyprland управление обоями осуществляется через две утилиты командной строки: hyprpaper для статичных изображений и mpvpaper для видео. При использовании нескольких мониторов это превращается в повторяющуюся ручную операцию. Ни один существующий инструмент не объединяет поддержку изображений и видеообоев в едином графическом интерфейсе с полноценной поддержкой мультимонитора.

В рамках проекта предполагалось:
разработать графический интерфейс для выбора и применения обоев на каждом мониторе отдельно;
реализовать поддержку статичных изображений через протокол IPC утилиты hyprpaper;
реализовать поддержку видеообоев через утилиту mpvpaper;
добавить режим слайдшоу с настраиваемым интервалом для каждого монитора независимо;
реализовать поворот изображения, автозапуск через systemd и двуязычный интерфейс;
опубликовать проект на GitHub с открытым исходным кодом и упаковать в AUR;
создать техническое руководство и разместить описание проекта на сайте практики.

Описание деятельности

Московский Политехнический университет осуществляет подготовку специалистов в области информационных технологий, программной инженерии, информационной безопасности и смежных технических направлений.

Одним из актуальных направлений подготовки является развитие практических навыков студентов в сфере разработки программного обеспечения и современных ИТ-инструментов. Проектная практика направлена на формирование у обучающихся компетенций самостоятельной разработки, документирования и публикации программных проектов.


3. Описание задания по проектной практике

В рамках проектной практики было необходимо изучить современные инструменты разработки и применить полученные знания при создании собственного проекта. Задание включало обязательную часть и вариативную часть по выбору.

Изучение Git

Были изучены основы работы с системой контроля версий Git:
создание репозиториев и настройка SSH-ключа;
работа с коммитами и осмысленными сообщениями;
работа с ветками;
публикация проекта в удалённом репозитории.

Изучение Markdown

Был изучен язык разметки Markdown, использованный для оформления всей документации проекта:
создание заголовков и списков;
вставка изображений и ссылок;
таблицы и блоки кода;
структурирование файлов в папке docs/.

Создание веб-сайта

В рамках обязательной части была разработана тема проекта по дисциплине «Проектная деятельность» — «Дешифратор для студентов и школьников» — и создан посвящённый ей статический веб-сайт.

В процессе разработки были созданы:
главная страница с интерактивным дешифратором на JavaScript, поддерживающим пять классических шифров: Код Морзе, Атбаш, Шифр Цезаря, Шифр Виженера, Шифр Вернама;
пошаговые объяснения для каждого шифра и интерактивные задания с проверкой ответа;
страницы о проекте, участниках, журнале прогресса и ресурсах;
маскот-персонаж (лисёнок) с тремя эмоциями, анимации, тёмная цветовая схема.

Сайт реализован на HTML5, CSS3 и ванильном JavaScript, работает без сервера.

Изучение технологий LLM

В рамках практики был пройден курс Hugging Face NLP Course, посвящённый большим языковым моделям и обработке естественного языка.

Во время прохождения курса были изучены:
архитектура Transformer и механизм self-attention;
три семейства моделей: Encoder-only (BERT), Decoder-only (GPT), Encoder-Decoder (T5);
библиотеки transformers и datasets;
токенизация текстов;
тонкая настройка моделей (Fine-Tuning).

Полученные знания были применены на практике: LLM-инструменты использовались как AI Pair Programmer при разработке HTML-структур сайта, написании CSS-сеток и генерации текстового контента.

Во время экскурсии были рассмотрены:

современные подходы к разработке программного обеспечения;

Полученный опыт позволил лучше понять организацию процессов разработки и особенности профессиональной деятельности в ИТ-сфере.

Вариативная часть — вариант 2.2: разработка GUI-утилиты HyprWall

В качестве вариативной части был выбран вариант 2.2 — практическая реализация технологии с нуля. Тема согласована с руководителем практики.

Было проведено исследование предметной области: изучены принципы работы оконного менеджера Hyprland, протокол IPC утилиты hyprpaper, интерфейс командной строки mpvpaper, фреймворк Qt6 и система сборки CMake. Проанализированы существующие аналоги: hyprpaper (только CLI, нет видео), swww (только CLI), waypaper (нет видео, ограниченный мультимонитор), mpvpaper (только CLI).

Реализован работающий прототип. Создано подробное техническое руководство в формате Markdown (docs/report.md) с описанием архитектуры, примерами кода и разделом «Модификация». Проект опубликован на GitHub, представлен на сайте практики.


4. Описание достигнутых результатов по проектной практике

В ходе выполнения проектной практики были получены практические навыки работы с современными технологиями разработки программного обеспечения.

Обязательная часть

Git-репозиторий настроен и регулярно пополняется коммитами с осмысленными сообщениями. Освоены основные команды: clone, add, commit, push, pull, branch, merge.

Создана Markdown-документация в папке docs/: project.md, members.md, journal.md, resources.md, partner_report.md, llm_report.md.

Разработан статический веб-сайт в папке site/. Главная страница содержит интерактивный дешифратор с пятью алгоритмами шифрования и заданиями с проверкой ответа. Сайт работает без сервера.

Пройден курс Hugging Face NLP Course, составлен отчёт docs/llm_report.md. LLM применялись при разработке сайта и HyprWall.

Оформлен отчёт о посещении экскурсии в Яндекс с фотоматериалами (docs/partner_report.md).

Вариативная часть — HyprWall

Разработана GUI-утилита HyprWall на C++ с использованием Qt6. Исходный код опубликован по адресу https://github.com/Rainkord/HyprWall.

Архитектура приложения включает шесть модулей: main.cpp (точка входа), MainWindow (логика интерфейса), MonitorDetector (определение мониторов через hyprctl monitors -j), ConfigManager (хранение конфигурации в JSON), WallpaperApplier (применение обоев через IPC и mpvpaper), Types.h и Strings.h (структуры данных и двуязычные строки).

Главное окно разделено на три зоны: верхняя панель с кнопками мониторов, левая панель настроек и правая галерея файлов с превью 200×150 пикселей.

В рамках раздела «Модификация» реализованы следующие возможности сверх базового MVP:
поддержка видеообоев через mpvpaper с автоматическим определением типа файла по расширению;
независимое слайдшоу для каждого монитора с настраиваемым интервалом (1 мин — 2 ч) и режимом медиа;
кнопка «Применить ко всем мониторам» (Apply All);
поворот изображения на 90°/180°/270° без изменения оригинала;
автозапуск через systemd (systemctl --user enable/disable);
двуязычный интерфейс RU/EN с мгновенным переключением без перезапуска;
асинхронный кэш превью через QtConcurrent — UI не зависает при большом количестве файлов;
пакет AUR с готовым PKGBUILD, установка командой yay -S hyprwall-git.

Основными результатами практики стали:
освоение системы контроля версий Git;
получение навыков работы с Markdown;
приобретение практического опыта веб-разработки на HTML, CSS, JavaScript;
изучение современных технологий искусственного интеллекта и LLM;
получение опыта применения ИИ-инструментов в разработке;
знакомство с организацией работы крупной ИТ-компании;
освоение разработки GUI-приложений на C++ и Qt6;
изучение протоколов межпроцессного взаимодействия в Linux;
получение опыта публикации open-source проекта.


ЗАКЛЮЧЕНИЕ

В ходе прохождения проектной (учебной) практики были изучены современные инструменты разработки программных проектов, технологии веб-разработки и возможности применения искусственного интеллекта при создании программного обеспечения.

В процессе выполнения практики были получены практические навыки работы с системой контроля версий Git, языком разметки Markdown, технологиями HTML, CSS и JavaScript, а также навыки организации структуры проектов и подготовки технической документации.
