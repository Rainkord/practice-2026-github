   ПРАКТИЧЕСКАЯ РЕАЛИЗАЦИЯ ТЕХНОЛОГИИ «С НУЛЯ»

2.1. Выбор темы и исследование

Выбрана тема: GUI-утилита HyprWall для управления обоями в оконном менеджере Hyprland.

Обоснование выбора. Hyprland — современный тайловый Wayland-композитор, популярный среди Linux-пользователей. Управление обоями в нём осуществляется через ручное редактирование конфигурационных файлов двух внешних утилит: hyprpaper (статичные изображения, ~/.config/hypr/hyprpaper.conf и IPC через hyprctl) и mpvpaper (видео и GIF, запускается командной строкой). При использовании нескольких мониторов это превращается в многошаговую повторяющуюся операцию, неудобную для ежедневного использования. Ни одна существующая утилита не объединяет поддержку и изображений, и видеообоев в едином GUI с полноценной поддержкой нескольких мониторов.

Проведён анализ аналогов:
— hyprpaper (сам демон) — CLI/конфиг, нет видео, нет GUI;
— swww — CLI, нет видео, нет GUI;
— waypaper — GUI на Python/GTK, нет видео, ограниченная поддержка мультимонитора;
— mpvpaper — CLI, есть видео, нет GUI;
— HyprWall (разработан в рамках практики) — GUI на C++/Qt6, есть видео, полная поддержка мультимонитора.

Изученные технологии:
— Qt6 / C++ — GUI-фреймворк: система сигналов и слотов, QProcess для запуска внешних процессов, QListWidget в режиме иконок, асинхронная загрузка превью через QtConcurrent;
— hyprpaper IPC — протокол взаимодействия через hyprctl hyprpaper preload / wallpaper;
— mpvpaper CLI — параметры --panscan, --keepaspect, --video-rotate, --volume, --loop;
— CMake — сборочная система Qt6-проекта (find_package(Qt6 COMPONENTS Widgets Concurrent));
— systemd user-сервисы — автозапуск через ~/.config/systemd/user/hyprwall.service;
— PKGBUILD — упаковка для Arch User Repository (AUR).

2.2. Архитектура реализованного прототипа

Проект построен по многослойной архитектуре с разделением ответственности. Исходный код размещён в папке src/ в репозитории HyprWall (github.com/Rainkord/HyprWall).

Модули:

main.cpp — точка входа. Инициализирует QApplication, применяет тёмную тему, запускает MainWindow.

MainWindow (MainWindow.h / MainWindow.cpp) — центральный класс. Содержит всю логику пользовательского интерфейса: монитор-бар, галерею, панель настроек. Управляет состоянием (m_pending — несохранённые изменения по каждому монитору), независимыми таймерами слайдшоу (m_ssState), кэшем превью изображений (m_thumbCache). Реализует кастомные события: paintEvent (фоновая заливка), mousePressEvent / mouseMoveEvent (перетаскивание окна без системных декораций).

MonitorDetector (MonitorDetector.h / MonitorDetector.cpp) — определяет подключённые мониторы. Запускает процесс hyprctl monitors -j, разбирает JSON-вывод, возвращает список структур MonitorInfo (имя, описание, разрешение, позиция, масштаб, частота обновления).

ConfigManager (ConfigManager.h / ConfigManager.cpp) — синглтон. Читает и записывает конфигурации всех мониторов в JSON-файл (~/.config/HyprWall/config.json). Хранит галерею файлов.

WallpaperApplier (WallpaperApplier.h / WallpaperApplier.cpp) — применяет обои. Для изображений: сначала пытается использовать IPC hyprpaper (hyprctl hyprpaper preload + wallpaper), при неудаче — перезаписывает hyprpaper.conf и перезапускает демон. Для видео: завершает предыдущий процесс mpvpaper на этом мониторе (pkill), запускает новый с параметрами fill/rotate/audio. Реализует поворот изображений через QImage::transformed с сохранением во временный файл.

Types.h — структуры данных: MonitorInfo, WallpaperConfig (путь, fill-mode, поворот, аудио, слайдшоу), GalleryItem. Перечисления FillMode (Cover / Contain) и WallpaperRotation.

Strings.h — двуязычная строковая база (RU/EN) для всех UI-элементов.

2.3. Пользовательский интерфейс

Главное окно разделено на три зоны:

Верхняя зона — MonitorBar: горизонтальная панель с кнопками-плашками для каждого подключённого монитора. Клик на плашку переключает контекст настроек.

Левая зона — панель настроек: fill-mode (Cover / Contain), поворот (0°/90°/180°/270°), аудио и громкость (только для видео), слайдшоу (тоггл-переключатель + интервал + режим медиа), автозапуск через systemd, переключатель языка (RU/EN), bind-hint (подсказка текущей привязки).

Правая зона — галерея: QListWidget в режиме IconMode с превью 200×150 пикселей, кнопка добавления файлов, удаление по правому клику, клик применяет обои к выбранному монитору.

Окно не имеет системных декораций: фон рисуется через paintEvent, перетаскивание реализовано через mouseMoveEvent.

2.4. Инструкция по сборке с нуля

Зависимости (Arch Linux): sudo pacman -S qt6-base cmake gcc hyprpaper mpvpaper

Сборка:
git clone https://github.com/Rainkord/HyprWall.git
cd HyprWall
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
./build/hyprwall

Установка через AUR: yay -S hyprwall

2.5. Дополнительные функции (раздел «Модификация»)

Базовой реализацией считается: выбор изображения и применение на один монитор.

Реализованные дополнения:

1. Поддержка видеообоев через mpvpaper. Приложение автоматически определяет тип файла по расширению (mp4, mkv, avi, webm, mov, gif и др.) и переключается между режимами. Для видео отображаются дополнительные элементы управления аудио и громкостью. При смене видео на изображение mpvpaper корректно завершается через pkill.

2. Независимое слайдшоу для каждого монитора. Каждый монитор имеет собственный QTimer с настраиваемым интервалом (1 мин / 5 мин / 15 мин / 30 мин / 1 ч / 2 ч) и режимом медиа (только фото / только видео / оба). Случайный выбор файла реализован через QRandomGenerator. Слайдшоу нескольких мониторов работают параллельно и независимо.

3. Apply All. Кнопка «Применить ко всем» применяет текущий файл на все подключённые мониторы сразу. WallpaperApplier::applyAll оптимизирует запуск: hyprpaper стартует один раз для всех изображений, mpvpaper запускается отдельно для каждого монитора с видео.

4. Поворот изображения. Поворот на 90°/180°/270° реализован через QImage::transformed (Qt::SmoothTransformation). Повёрнутый вариант сохраняется в ~/.cache/HyprWall без изменения оригинального файла.

5. Автозапуск через systemd. Тоггл в UI вызывает systemctl --user enable/disable hyprwall. Файл юнита поставляется с пакетом в папке systemd/.

6. Двуязычный интерфейс (RU/EN). Все строки вынесены в Strings.h. Переключение языка применяется мгновенно через retranslateUi() без перезапуска приложения.

7. Асинхронный кэш превью. Загрузка и масштабирование превью происходит в фоновых потоках через QtConcurrent::run. Механизм «поколений» (m_thumbGeneration) предотвращает применение устаревших результатов при быстром обновлении галереи. UI не зависает при добавлении большого количества файлов.

8. Упаковка в AUR. Проект содержит готовый PKGBUILD для Arch User Repository. Пользователи Arch Linux могут установить утилиту командой yay -S hyprwall.
