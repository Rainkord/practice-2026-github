4.2. Вариативная часть — реализация технологии с нуля

Исследование и анализ аналогов

Изучен оконный менеджер Hyprland и его экосистема управления обоями. Управление обоями осуществляется через две утилиты: hyprpaper (статичные изображения, конфигурация через ~/.config/hypr/hyprpaper.conf и IPC-команды hyprctl hyprpaper) и mpvpaper (видео и GIF, командная строка). Выявлена проблема: ни одна из существующих утилит не объединяет поддержку изображений и видеообоев в едином GUI с полноценной поддержкой нескольких мониторов. Ближайший аналог — waypaper (Python/GTK) — не поддерживает видео и имеет ограниченный мультимонитор.

Реализованная архитектура

Проект написан на C++ с использованием Qt6. Исходный код расположен в src/ репозитория HyprWall. Приложение разделено на шесть модулей:

main.cpp — точка входа, инициализация QApplication и запуск MainWindow.

MainWindow — главный класс UI. Реализует монитор-бар (панель с кнопками мониторов), галерею файлов, панель настроек. Управляет состоянием (m_pending), таймерами слайдшоу (m_ssState), кэшем превью (m_thumbCache). Кастомные события: paintEvent (фон), mouseMoveEvent (перетаскивание окна).

MonitorDetector — запускает hyprctl monitors -j, разбирает JSON, возвращает список MonitorInfo (имя, разрешение, позиция, масштаб, частота).

ConfigManager — синглтон, хранит конфигурацию мониторов в ~/.config/HyprWall/config.json и список галереи.

WallpaperApplier — применяет обои. Для изображений: IPC hyprpaper (hyprctl hyprpaper preload + wallpaper), при неудаче — перезапись conf + pkill + restart. Для видео: pkill предыдущего mpvpaper + запуск нового с параметрами fill/rotate/audio. Поворот: QImage::transformed, результат в ~/.cache/HyprWall.

Types.h и Strings.h — структуры данных (MonitorInfo, WallpaperConfig, GalleryItem, перечисления FillMode и WallpaperRotation) и двуязычная строковая база RU/EN.

Пользовательский интерфейс

Главное окно без системных декораций разделено на три зоны: верхний монитор-бар (выбор монитора), левая панель настроек (fill-mode, поворот, аудио, слайдшоу, автозапуск, язык), правая галерея (превью 200×150, добавление/удаление файлов, применение обоев кликом).

Инструкция по сборке

Зависимости: qt6-base, cmake, gcc, hyprpaper, mpvpaper.
Команды сборки: git clone https://github.com/Rainkord/HyprWall.git → cmake -B build -DCMAKE_BUILD_TYPE=Release → cmake --build build -j$(nproc).
Установка через AUR: yay -S hyprwall.

Дополнительные реализованные функции (сверх базового MVP)

1. Поддержка видеообоев (mpvpaper). Автоматическое определение типа файла по расширению. Отдельные UI-элементы для видео (аудио, громкость). Корректное завершение mpvpaper при смене видео на изображение.

2. Независимое слайдшоу для каждого монитора. Каждый монитор имеет свой QTimer с интервалом на выбор (1 мин, 5 мин, 15 мин, 30 мин, 1 ч, 2 ч) и режимом (фото / видео / всё). Файл выбирается случайно через QRandomGenerator. Таймеры нескольких мониторов работают параллельно.

3. Apply All. Одной кнопкой текущие обои применяются ко всем мониторам. Оптимизированный запуск: hyprpaper стартует один раз, mpvpaper — отдельно для каждого монитора с видео.

4. Поворот изображения на 90°/180°/270° через QImage::transformed. Повёрнутая копия сохраняется во временный файл, оригинал не затрагивается.

5. Автозапуск через systemd. Переключатель в UI вызывает systemctl --user enable/disable hyprwall. Юнит-файл поставляется в пакете.

6. Двуязычный интерфейс RU/EN. Все строки в Strings.h. Мгновенное переключение через retranslateUi() без перезапуска.

7. Асинхронный кэш превью. Загрузка превью в фоновых потоках (QtConcurrent::run). Механизм поколений (m_thumbGeneration) исключает устаревшие результаты. UI не зависает при большом количестве файлов.

8. Пакет AUR. Готовый PKGBUILD позволяет установить утилиту командой yay -S hyprwall.
