1. ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

1.1. Название проекта

HyprWall — графическая утилита для управления обоями рабочего стола в оконном менеджере Hyprland под Linux.

Репозиторий: https://github.com/Rainkord/HyprWall

1.2. Цели и задачи проекта

Цель: создать удобную GUI-утилиту для управления обоями в Hyprland, которая заменяет ручное редактирование конфигурационных файлов.

Задачи:
— изучить работу hyprpaper (протокол IPC) и mpvpaper (интерфейс CLI) для видео;
— проанализировать аналоги (waypaper, swww) и определить недостатки;
— реализовать работающий MVP: выбор изображения из GUI и применение на несколько мониторов;
— добавить поддержку видеообоев, слайдшоу, поворот, автозапуск, двуязычный интерфейс;
— опубликовать проект на GitHub, сделать пакет AUR;
— задокументировать проект в репозитории и представить на сайте.

Выполнение вариативной части — разработка HyprWall

Проведён анализ аналогов. В Hyprland управление обоями требует ручного редактирования двух конфигурационных файлов. Ближайший аналог — waypaper (нет поддержки видео, ограниченный мультимонитор). HyprWall решает оба пробела.

HyprWall написан на C++ с Qt6. Функциональность:
— выбор монитора через панель сверху (данные из hyprctl monitors -j);
— галерея файлов с превью (QListWidget в режиме иконок, асинхронная загрузка через QtConcurrent);
— применение статичных обоев через IPC hyprpaper (hyprctl hyprpaper preload / wallpaper);
— применение видеообоев через mpvpaper;
— независимое слайдшоу для каждого монитора (QTimer, QRandomGenerator, настраиваемый интервал и режим медиа);
— поворот изображения через QImage::transformed без изменения оригинала;
— автозапуск через systemctl --user enable/disable;
— двуязычный интерфейс RU/EN с мгновенным переключением;
— пакет AUR (PKGBUILD, установка командой yay -S hyprwall-git).

Исходный код размещён в https://github.com/Rainkord/HyprWall. Техническое руководство — в docs/report.md репозитория практики. Страница проекта представлена на сайте (site/).
